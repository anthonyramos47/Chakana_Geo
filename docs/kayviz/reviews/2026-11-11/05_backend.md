# kayviz backend review (backend expert, branch `debugging`)
Versions: Python 3.11.14, uvicorn 0.46.0, fastapi 0.136.0, starlette 1.0.0, websockets 16.0, numpy 2.4.1.

## 1) Summary
- REVIEW_2026-11 fixes are in: callbacks in a worker thread, slider coalescing, results to every tab, binary wire, SO_REUSEADDR probe. The event loop no longer blocks.
- Concurrency, three bugs reproduced: the per-app lock is released when a tab closes during a callback, so two user callbacks then run at once; pushes made on the loop are fire-and-forget tasks that can arrive out of order (viewer drops quantities that arrive before their mesh); asyncio Event/Lock created once per app outlive a server restart and fail on the new loop (HTTP 500, then show(block=True) spins).
- Scene buffer drifts from the viewer: remove() leaves quantities; kv.remove inside a callback misses the app buffer; one object that cannot be encoded leaves every new tab with an empty scene, silently.
- Security: all endpoints unauthenticated, no Origin/Host checks: any web page can read the scene over a WebSocket, trigger callbacks, shut the server down, steal screenshot jobs; DNS rebinding gives full access.
- Lifecycle/protocol: on macOS the port probe reports a port held by a 0.0.0.0 server as free (kayviz binds it and hides that server); screenshot handshake leaks jobs/results and lets any tab claim a job; numpy scalars in lists and NaN in headers break encoding.

## 3) Security notes
- Cross-site WebSocket hijacking (VERIFIED: Origin http://evil.example received the whole scene): any page can read geometry, send _callback (runs user code: exports, file writes), _set_state, GUIApp actions.
- CSRF shutdown (VERIFIED): POST /api/_shutdown from any Origin with text/plain → 200, server down (no-cors fetch suffices). JSON pushes from foreign pages rejected (422); GET /screenshot/pending still has an effect (takes jobs).
- DNS rebinding (VERIFIED: Host attacker.example → 200): every HTTP route becomes same-origin for the attacker (read /load, push/remove/clear).
- Shared machines: any local user can shut down / read other users' servers; --host 0.0.0.0 exposes everything unauthenticated.
- panel_js and static files fine (path from code; StaticFiles blocks traversal).
- Fix: per-server random token (HttpOnly cookie set by /, required on WS, POST, screenshot routes); TrustedHostMiddleware (127.0.0.1, localhost); WS Origin check; token for /api/_shutdown (kill_servers reads it from a lock file).

## 4) Top 5 recommendations
1. One ordered outbound path per client (queue + single sender, latest message per object; register after snapshot; producers return after buffering): BE3, BE8, BE14.
2. Handler lock that survives cancellation; per-loop asyncio primitives recreated on restart; sleep on non-200 (BE1, BE2).
3. Consistent buffer: validate/encode before buffering and raise; remove/re-register with quantities; remove via sink; targets before quantities; encode handles numpy scalars, mixed lists, NaN (BE4-BE7).
4. Lock down localhost: token, Host allowlist, WS Origin check, authenticated shutdown, ws_max_size ~1 MB.
5. Screenshots over the target app's WS to one tab with TTL, cancel, size cap (BE10); bind uvicorn to a held socket + connect probe + retry (BE9); kill_servers from KAYVIZ_PORT (BE17).
